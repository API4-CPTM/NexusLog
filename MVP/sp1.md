# 📌 MVP - NexusLog-CPTM

## 🎯 Objetivo do MVP
- O MVP1 busca solucionar a dificuldade de extrair, organizar, tratar e visualizar os dados de estoque da CPTM, criando uma base confiável e consistente afim de possibilitar a análise e a extração de informações para a construção do painel em cima de dados confiáveis.
- Por meio do tratamento dos dados esperamos que seja possível transformar os dados brutos de estoque em informações organizadas, possibilitanto enxergarmos os maiores problemas a serem solucionados na gestão de estoque da CPTM.
- Será entregue uma primeira versão que permita de centralizar e apresentar informações relevantes do estoque de forma visual facilitando a análise dos dados e criando uma base para a implementação dos indicadores e funcionalidades previstas nas próximas Sprints.
---

## 📝 Descrição da Solução
> Nessa sprint apresentaremos a versão inicial do nosso painel, o primeiro foco é preparar os dados, estruturar nossos modelos e disponibilizar as primeiras visualizações para o dashboard
* Extração dos dados brutos de estoque do ERP ALVO
* Tratamento e limpeza dos dados utilizando Python
* Remoção de inconsistências e duplicidades
* Estruturação inicial do banco/modelo de dados
* Criação da primeira versão do Dashboard no Power BI
* Organização e versionamento dos artefatos do projeto no GitHub
> Por ainda ser MVP1 não teremos toda estrutração e funcionalidades que posteriormente terão, ao decorrer do projeto como todos indicadores (giro de estoque,cobertura em dias ou curva ABC)
> O escopo dessa sprint se concentra em garantir que ps dados sejam confiáveis e de qualidade, afim de nos permitir o inicio da nossa solução.
